# 题集划分

企业管理与通用任务是两个正式公开题集，发布在Hugging Face（下载见[题集](../datasets/README.md)），分别运行、分别出分。示例任务随仓库提供，用于框架自测、工具调试和出题参考，不计入正式成绩。

| 入口 | 用途 |
| --- | --- |
| `datasets/lg-bench-enterprise-v1.0/tasks` | 企业管理30题 |
| `datasets/lg-bench-general-v1.0/tasks` | 通用35题 |
| `examples/tasks` | 独立合成示例，随仓库提供 |

划分以场景实例为单位。相同原题、共享同一底层实例或只换名称、金额、日期的变体不能一边用于开发调参、一边声称是独立评测题。

公开题面、答案、轨迹或反馈用于训练、few-shot、参数选择或逐题错误分析时，应在成绩中披露。各题集、版本和调优口径分别报告；不得把公开题成绩当作未见实例的泛化结论。

任务输入和评分在同一批运行期间保持冻结。变更后重新计算摘要，按新版本运行，保留历史成绩及其配置。
