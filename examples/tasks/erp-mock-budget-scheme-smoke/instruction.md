你可以使用名为 `erp` 的 MCP 服务，它连接着一个 ERP 系统（全面预算域）。

请调用 `erp` 服务里查询**预算方案**的工具，从返回的 `history` 里取**前 5 条**（按返回顺序，不要排序），
然后把结果写入 `/workspace/output/budget-schemes.json`，格式如下：

```json
{
  "tool": "<你调用的 MCP 工具名>",
  "schemes": [
    {"number": "<预算方案编码>", "name": "<预算方案名称>"}
  ]
}
```

字段对应关系：返回每行的 `src_number` 填 `number`，`src_name` 填 `name`。

要求：

- `schemes` 只能包含工具真实返回的预算方案，按返回顺序取前 5 条，不要编造、补全或改写；
- 只做查询，不要调用任何新增、修改、提交或删除类的工具；
- 不需要写其他文件。
